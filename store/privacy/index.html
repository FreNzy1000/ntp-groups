NTP Groups Privacy Policy

Effective date: 18 August 2026

NTP Groups is a New Tab extension for Microsoft Edge and other compatible Chromium-based browsers. It organizes favorite websites into groups. This policy explains what information the extension handles and what happens to it.

Information handled by NTP Groups

  • shortcut names entered by the user;
  • website URLs entered by the user;
  • group names and shortcut ordering;
  • extension preferences and layout state;
  • search text entered into the New Tab search field.

How the information is used

Shortcut data, group data, layout state, and preferences are used only to render and operate the user's New Tab page.

Search text is passed to the browser's official search API so the browser can open results using the default search provider selected by the user. NTP Groups does not select, replace, or override the user's search provider.

Storage

Shortcut data, group data, layout state, and preferences are stored locally using the browser extension storage API. They are not uploaded to a server operated by the NTP Groups developer.

Data sharing and transmission

NTP Groups does not transmit saved shortcut data, group data, layout state, or preferences to the developer or to a developer-operated server.

NTP Groups has no advertising, analytics, tracking, telemetry, account system, or developer-operated backend.

When the user performs a search, the browser's default search provider receives the search query as part of normal browser search behavior. That provider's handling of the query is governed by its own privacy policy.

When favicons are displayed, NTP Groups uses the browser's built-in favicon mechanism for URLs saved by the user. NTP Groups does not send those URLs to a developer-operated favicon service.

Sale of data and advertising

NTP Groups does not sell user data and does not use user data for advertising, profiling, credit decisions, or unrelated purposes.

Human access

Because NTP Groups does not upload user data to a developer-operated service, the developer does not receive or routinely access the user's saved shortcut data.

Security

NTP Groups contains its application logic inside the extension package and does not load or execute remote code.

User control and deletion

Users can edit or delete individual saved sites and groups from the extension. Users can also reset the extension's saved layout from its settings. Removing the extension removes its extension-local storage according to browser behavior.

Purpose limitation

The use of information handled by NTP Groups is limited to providing the extension's single user-facing purpose: a grouped New Tab launcher with browser-default search. NTP Groups does not transfer user information for personalized advertising or unrelated purposes.

Contact

Support requests can be submitted through the public NTP Groups GitHub Issues page. NTP Groups does not require a separate public support email in this privacy policy.
