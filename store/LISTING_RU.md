# NTP Groups — страница Chrome Web Store

## Название
NTP Groups

## Краткое описание
Организуйте любимые сайты в группы на новой вкладке, сохраняя текущую поисковую систему браузера.

## Полное описание
NTP Groups заменяет страницу новой вкладки компактной панелью быстрого доступа с группами сайтов.

Часто используемые сайты можно оставить в корне, связанные сайты объединить в группы и открывать группы прямо на странице новой вкладки. Сайты и группы можно добавлять, изменять, перемещать, сортировать и удалять непосредственно из интерфейса.

Основные возможности:

- Группы для избранных сайтов.
- Предпросмотр сайтов внутри группы.
- Перетаскивание и изменение порядка ярлыков.
- Перемещение сайтов между корнем и группами.
- Поиск только через текущую поисковую систему браузера с использованием официального API поиска.
- Локальное хранение названий сайтов, URL, структуры и настроек.
- Без рекламы, аналитики, трекеров, удалённых скриптов и серверной части разработчика.

Конфиденциальность: NTP Groups обрабатывает названия ярлыков, URL, структуру и настройки, которые пользователь сам сохраняет. Эти данные остаются локально в браузере и не передаются разработчику. Текст поискового запроса передаётся браузерному API поиска и обрабатывается поисковой системой, выбранной пользователем в настройках браузера.

У NTP Groups одна задача: сделать новую вкладку удобным местом для организации и быстрого открытия любимых сайтов.
